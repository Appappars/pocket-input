# Протокол фазы 1 (трекпад + клавиатура по HID)

Спека: `spec/PocketInput-SPEC.md` 5.2 (фаза 1), 4.5–4.8 (экраны, жесты, клавиатура, настройки).
Правило: фаза не закрыта, пока в таблице приёмки есть «не проверено».

## Что должно работать в конце фазы

Полноценный трекпад (движение, тап, двойной тап, правая кнопка, drag с фиксацией ЛКМ,
скролл двумя пальцами, три пальца — рабочий стол и переключение окон) и клавиатура с
sticky-модификаторами, всё — через HID-композит, без софта на ПК.

## Изменение решения: системная клавиатура (18.11.2026)

Владелец продукта после живого теста: собственная раскладка неудобна, нужна клавиатура телефона.
Спека 4.7 обновлена, реализация заменена (`0.2.1-ime`, коммит ниже):

- невидимое поле держит фокус и вызывает IME; изменения текста диффятся (`TextDiff`) →
  удаления в Backspace, вставленный текст в `keyTap` по таблице символов (`CharMap`);
- на панели остались только модификаторы, Esc/Tab/Del/Backspace и стрелки;
- кириллица маппится на позиции клавиш русской раскладки, заглавные — с `LSHIFT`;
- эмодзи и CJK в HID-ветке не выражаются, показывается счётчик пропущенных символов.

Найдено прогоном: панель спецклавиш уезжала **под** системную клавиатуру — окно не сообщало
Compose про IME insets. Исправлено `android:windowSoftInputMode="adjustResize"` в манифесте.

Проверено на эмуляторе (`adb shell input text`, лог `PocketInputHID`):

| Проверка | Команда | Результат в логе |
|---|---|---|
| системная клавиатура поднимается | `dumpsys input_method` | `mInputShown=true` |
| латиница по символам | `input text "abc"` | `keyTap usage=0x4`, `0x5`, `0x6` |
| удаление из IME | `input keyevent 67` | `keyTap usage=0x2a` (Backspace) |
| sticky Ctrl | тап Ctrl → `input text "c"` | `keyTap usage=0x6 mods=0x1` |
| модификатор сбрасывается | затем `input text "d"` | `keyTap usage=0x7 mods=0x0` |
| стрелка с панели | тап «←» | `keyTap usage=0x50` |
| панель видна над IME | скриншот `phase1-ime-keyboard.png` | панель между полем и Gboard, без перекрытий |

Юнит-тесты: **59, 0 провалов** (`CharMapTest` 7, `TextDiffTest` 8 добавлены).

## Правки по итогам живого использования (18.11.2026, сборка 0.2.3)

Владелец продукта после теста на телефоне потребовал:

| Что просил | Что сделано |
|---|---|
| запятая уходила как «б» | знаки препинания в русском контексте маппятся по русской раскладке (`TextDiff`→`CharMap.map(ch, ruLayout)`): `,` = Shift+`/`, `.` = `/`; причина дефекта — в HID уходит позиция клавиши, а в русской раскладке запятая стоит на другой клавише |
| кнопка стирания в IME не работает | поле ввода переведено на `TextFieldValue` с курсором в конце и невидимым заполнителем (`U+200B`), поэтому «стереть» всегда меняет текст и уходит как Backspace (раньше курсор стоял в начале — удалять было нечего) |
| пустое место над клавиатурой — под тачпад | `TrackpadSurface` вынесен из `TrackpadScreen` в отдельный composable и вставлен на экран клавиатуры |
| убрать панель клавиш | панель Ctrl/Shift/Alt/Win, Esc/Tab/Del и стрелки удалена: осталась системная клавиатура, «Назад» и значок ⌨ для повторного вызова IME |
| двойной тап с удержанием = перетаскивание | реализовано: второй тап, удержанный дольше `TAP_AND_HOLD_MS = 150` мс, нажимает ЛКМ и ведёт объект, отпускание отпускает; короткий второй тап остаётся двойным кликом |

Проверено на эмуляторе (`logcat -s PocketInputHID`, `adb shell input`):

| Проверка | Результат |
|---|---|
| набор латиницы | `keyTap usage=0x4/0x5/0x6` |
| удаление на пустом поле | `keyTap usage=0x2a` |
| одиночный тап | 1 × `tap requested` |
| два быстрых тапа | 2 × `tap requested` |
| тап + удержание с движением | `tap requested` → `pressButton bit=1` → `releaseButton bit=1` |
| свайп по тачпаду при открытой IME | ошибок нет, `mInputShown=true` |

Юнит-тесты: 60, 0 провалов (добавлен `russianLayout_movesPunctuationToRussianKeys`).

Осознанные потери: с панелью ушли сочетания Ctrl+C/V и Alt+Tab с клавиатурного экрана
(трёхпальцевый свайп на тачпаде остался). Эмодзи и CJK в HID-ветке не передаются — фаза 2.
