# Протокол фазы 1 (трекпад + клавиатура по HID)

Спека: `spec/PocketInput-SPEC.md` 5.2 (фаза 1), 4.5–4.8 (экраны, жесты, клавиатура, настройки).
Правило: фаза не закрыта, пока в таблице приёмки есть «не проверено».

## Что должно работать в конце фазы

Полноценный трекпад (движение, тап, двойной тап, правая кнопка, drag с фиксацией ЛКМ,
скролл двумя пальцами, три пальца — рабочий стол и переключение окон) и клавиатура с
sticky-модификаторами, всё — через HID-композит, без софта на ПК.

## Прогон на эмуляторе (Android 14, Pixel 6) — 2026-11-18

Проверка «по коду» до живого железа: сборка, тесты, все четыре экрана, переключение слоёв.

|---|---|---|

| Юнит-тесты | `gradle testDebugUnitTest` | **44 теста, 0 провалов** (DescriptorsTest 5, KeyMapTest 20, TrackpadMathTest 19) |
| Экран подключения | запуск + uiautomator | «HID-профиль: доступен», «Состояние HID: registered» |
| Экран трекпада | переход по кнопке | подсказка жестов, область трекпада ≈ 65 % экрана, кнопки ЛКМ/ПКМ/Клавиатура/Настройки |
| Экран клавиатуры | переход по кнопке | 5 рядов (EN), слои EN/РУ/123/+=-, клавиатура прижата к низу, без прокрутки |
| Слой РУ | тап по «РУ» | буквы ЙЦУКЕН + постоянная подсказка про раскладку ПК |
| Экран настроек | переход по кнопке | ползунки чувствительности 0.2–4.0 и скролла 0.2–3.0, вибро, выбор темы |
| Падения | `logcat -b crash` | пусто на всех переходах |

Скриншоты: `phase1-trackpad.png`, `phase1-keyboard.png`, `phase1-keyboard-ru.png`, `phase1-settings.png`.

Найдено и исправлено прогоном: клавиатура стояла по центру экрана с провалом сверху (вертикальное
выравнивание строк `CenterVertically`) — заменено на `Alignment.Bottom`, клавиши прижаты к нижней границе.

Поправка дизайна после просмотра скриншота: трекпад занимает 2/3 экрана, одной рукой удобны
только кнопки — большой палец не достаёт до верхней половины области. Для фазы 1 принято
(трекпад = «на столе или двумя руками»); в фазе 4 при магнетизме это пересмотреть.
